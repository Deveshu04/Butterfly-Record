# Demo video

The one-minute tour of the Windows app, made with [Remotion](https://www.remotion.dev).
The screenshots in `public/shots` are taken from the real app.

```
npm install
npm run dev                                  # preview in Remotion Studio
npx remotion render Demo out/demo.mp4        # render the video
```

This folder is not part of the pnpm workspace and CI does not build it. Remotion has its own
[licence](https://github.com/remotion-dev/remotion/blob/main/LICENSE.md).
